# Gemini Context

This document provides context for the Gemini CLI agent.

## Project Overview

The goal of this project is to build a web builder with Next.js and Sanity. The repository should be clean, maintainable, and scalable.

## Tech Stack

- Next.js
- Sanity
- TypeScript
- ESLint
- Prettier

## Conventions

- **ESLint and Prettier:** The project uses ESLint and Prettier for code formatting and quality. The configuration is in `eslint.config.mjs` and `.prettierrc`.
- **Import Order:** The `eslint-plugin-simple-import-sort` plugin is used to enforce a consistent import order.
- **Component Naming:** Components should be named in PascalCase.
- **Format on Save:** The `.vscode/settings.json` file is configured to format the code on save.
